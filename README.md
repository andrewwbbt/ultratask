# Telegram-бот для задач

Личный бот для списка дел и погоды. Задачи, история действий, сведения о пользователях и выбранный город сохраняются в SQLite (`tasks.db`), поэтому остаются после перезапуска. Бот работает в личном чате.

Все команды находятся в постоянной кнопке **«Меню»** слева от строки ввода в личном чате — рядом со скрепкой, как в обычном интерфейсе Telegram. Бот регистрирует команды при запуске и дополнительно настраивает меню конкретного чата после `/start`. В сообщении `/start` есть кнопки добавления, просмотра и выполнения задач, а также погоды. Команда `/help` по-прежнему отправляет текстовую подсказку. После обновления кода перезапустите бота, отправьте ему `/start` и при необходимости откройте чат заново, чтобы Telegram обновил панель ввода.

## Запуск

Нужен Python 3.10 или новее. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.

В PowerShell из этой папки:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` замените `BOT_TOKEN` на настоящий токен. При необходимости измените `TIMEZONE` (название IANA, например `Europe/Moscow`) и `DB_PATH`. Затем запустите:

```powershell
python bot.py
```

На Linux/macOS вместо команд создания и активации окружения используйте `python3 -m venv .venv` и `source .venv/bin/activate`, затем `cp .env.example .env` и `python bot.py`.

Не публикуйте `.env` и файл базы данных. Для резервной копии сохраните `tasks.db` при остановленном боте.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Главное меню |
| `/help` | Подсказка |
| `/add` | Добавить задачу по шагам |
| `/tasks` | Открытые задачи с кнопками |
| `/today` | Задачи со сроком сегодня или раньше, задачи без срока, созданные сегодня, и краткий прогноз погоды |
| `/week` | Открытые и выполненные задачи, созданные за последние семь дней |
| `/search` | Поиск задач по названию, статусу и дате |
| `/history` | История создания, изменений, выполнения и удаления задач |
| `/city` | Выбрать город для погоды |
| `/city Москва` | Найти город сразу по названию |
| `/weather` | Текущая погода и прогноз на сегодня |
| `/done` | Выбрать открытую задачу для выполнения по названию |
| `/done 12` | Отметить задачу #12 выполненной |
| `/edit 12` | Изменить название, срок, приоритет или напоминание |
| `/delete 12` | Удалить задачу после подтверждения |
| `/stats` | Число открытых и выполненных задач |
| `/cancel` | Отменить текущий ввод |

Кнопки «Задачи» и «Сегодня» выводят подходящие задачи по возрастанию номера: №1, №2 и далее. Приоритет и срок не меняют порядок списка. Команда `/done` без номера показывает кнопки с названиями открытых задач (по 10 на странице). После выбора бот подтверждает номер и название выполненной задачи.

Задача без срока попадает в «Сегодня» в день создания по часовому поясу `TIMEZONE`. На следующий день она остаётся в «Задачах», но исчезает из «Сегодня». Задачи со сроком показываются в «Сегодня», если срок наступает сегодня или уже прошёл.

## Поиск, неделя и история

`/search` предложит ввести запрос. Можно указать его сразу в команде:

```text
/search молоко
/search статус=открыта
/search статус=выполнена дата=12.10.2026
/search купить молоко статус=все дата=12.10.2026
```

Название ищется без учёта регистра. Допустимые статусы: `открыта`, `выполнена`, `все`. Фильтр `дата=ДД.ММ.ГГГГ` совпадает с датой создания, сроком или датой выполнения по часовому поясу `TIMEZONE`. Фильтры можно сочетать. Поиск показывает существующие открытые и выполненные задачи; удалённые задачи доступны только в `/history`.

`/week` показывает задачи, **созданные** сегодня и за шесть предыдущих календарных дней в часовом поясе `TIMEZONE`, независимо от их срока и текущего статуса. Удалённые задачи в недельный список не входят. `/history` показывает действия от новых к старым; название удалённой задачи остаётся в журнале. Номер в истории — тот, который был у задачи в момент действия. Результаты выводятся по 10 записей на страницу.

При запуске бот автоматически создаёт таблицы `users`, `interactions` и `task_history`. В `users` хранятся Telegram ID, ID личного чата, имя, username и время первого/последнего обращения. Для пользователей из старой базы время первоначально берётся из дат их задач. В `interactions` сохраняются время и тип обращения (команда, кнопка или сообщение), без текста личных сообщений. В `task_history` сохраняются действия с задачами и значения изменённого поля. У каждой записи есть ID владельца; команды показывают только его данные. Журнал заполняется для новых действий после обновления бота, старые действия восстановить нельзя.

## Погода

Отправьте `/city` и напишите название города либо сразу `/city Москва`. Если найдено несколько мест, выберите нужное кнопкой: в подписи указаны регион и страна. Повторяющиеся одинаковые подписи скрываются. Кнопка «🌤 Погода» доступна после `/start`; `/weather` показывает текущую температуру, погодные условия, количество осадков за текущий интервал и прогноз на сегодня: минимум и максимум температуры, погодные условия и максимальную вероятность осадков. Значок погоды соответствует текущим условиям. Под прогнозом есть кнопка «Сменить город». Краткий прогноз появляется при нажатии «Сегодня» и по `/today`, даже если задач на сегодня нет. Пока город не выбран, бот предложит выбрать его.

Поиск городов работает через [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api), прогноз — через [Open-Meteo Weather Forecast API](https://open-meteo.com/en/docs). Ответы приходят в JSON. Для некоммерческого использования ключ API не требуется. Нужен доступ в интернет; если сервис временно недоступен, бот сообщит об этом, а список задач продолжит работать. Прогноз «сегодня» рассчитывается по местному времени выбранного города (`timezone=auto`), а отбор задач — по `TIMEZONE` из `.env`.

В таблице `user_locations` хранятся ID пользователя, название, регион и страна выбранного города, его широта и долгота. При обновлении старой базы бот добавляет поле региона, сохраняя выбранный город и задачи. Для ранее выбранного города регион появится после повторного выбора через `/city`. Отдельный файл с данными не нужен.

Срок можно выбрать кнопками «Сегодня» или «Завтра», а затем выбрать предложенное время (09:00, 12:00, 18:00) либо ввести другое как `ЧЧ:ММ`. Прошедшие часы скрываются, а срок проверяется ещё раз при нажатии. Кнопка «Ввести дату» позволяет ввести полный срок `ДД.ММ.ГГГГ ЧЧ:ММ`; «Без срока» убирает срок. Такой же выбор доступен при изменении задачи. Время считается по часовому поясу из `.env`. Напоминание можно выбрать за 10 минут, за час или за день до срока. Если срок не задан, напоминание выключено. Бот проверяет напоминания раз в минуту. После перезапуска он отправит ранее не отправленные напоминания, срок которых уже наступил.

В базе хранятся ID пользователя и чата, название задачи, приоритет, срок, статус, дата создания и выполнения, настройка и факт отправки напоминания. Каждый пользователь видит и изменяет только свои задачи.

Номера назначаются только открытым задачам каждого пользователя. После выполнения или удаления оставшиеся открытые задачи перенумеровываются по порядку создания: №1, №2 и далее. Следующая новая задача получает номер после последней открытой. Выполненные задачи остаются в базе для `/stats`, но не занимают номера. При запуске этой версии сохранённые задачи также перенумеровываются; актуальный список можно посмотреть через `/tasks`. Старые сообщения в чате не меняются, но их кнопки привязаны к постоянным внутренним ID и не затронут другую задачу.
