# Отчет по лабораторной работе

**Тема:** Telegram-бот для управления личными задачами  
**Результат:** работающий проект на Python с хранением задач в SQLite

## 1. Описание задачи

Цель лабораторной работы — разработать Telegram-бота, с помощью которого пользователь ведет список дел в личном чате. Бот позволяет добавить задачу, изменить ее название, приоритет, срок и напоминание, отметить задачу выполненной или удалить ее. Для просмотра предусмотрены общий список, список на сегодня и статистика.

Основные команды: `/start`, `/help`, `/add`, `/tasks`, `/today`, `/done`, `/edit`, `/delete`, `/stats`. Дополнительно реализована `/cancel` для отмены ввода. Команды доступны через постоянную кнопку Telegram **«Меню»** слева от строки сообщения. Кнопки «Задачи» и «Сегодня» показывают задачи по возрастанию номера.

### Какую проблему решает бот

Когда дела записаны в разных местах, легко пропустить срок или забыть о задаче. Бот хранит их в одном чате, показывает актуальные дела, напоминает о сроках и помогает фиксировать выполненную работу. Данные остаются в базе после перезапуска программы.

### Почему выбрали именно эту задачу

Управление задачами — понятный и полезный сценарий для практики. Он позволяет в одном проекте изучить Telegram-команды и кнопки, пошаговый ввод, базу данных, обработку дат, напоминания и проверку ошибок. При этом результат можно применять в повседневной жизни.

### Финальный промпт

Сводная формулировка требований после всех уточнений:

> Создай в папке `ULTRA_TASKS` Telegram-бота на Python с библиотекой `python-telegram-bot`. Бот должен добавлять, показывать, редактировать, удалять и завершать задачи, поддерживать приоритеты, сроки, напоминания и статистику. Реализуй команды `/start`, `/help`, `/add`, `/tasks`, `/today`, `/done`, `/edit`, `/delete`, `/stats`; при необходимости добавь отмену ввода. Зарегистрируй все команды в постоянной кнопке Telegram «Меню» слева от поля ввода. В главном сообщении оставь кнопки «Добавить», «Задачи» и «Сегодня». В «Сегодня» показывай задачи со сроком сегодня или раньше, а также задачи без срока, созданные сегодня. Выводи открытые задачи по порядку создания под последовательными номерами №1, №2 и далее. После выполнения или удаления перенумеруй оставшиеся открытые задачи; выполненные сохрани для статистики без номера. Старые кнопки должны ссылаться на внутренний ID и не управлять другой задачей. Отвечай кратко на русском языке, подтверждай действия и сообщай об ошибках. Храни данные каждого пользователя в SQLite. Подготовь код, зависимости, инструкцию запуска и пример `.env`.

## 3. Стек технологий

| Технология или библиотека | Для чего используется | Почему выбрана |
| --- | --- | --- |
| Python 3.10+ | Основной язык программы | Удобен для небольшого бота и содержит нужные средства для работы с SQLite и датами. |
| `python-telegram-bot[job-queue]==22.8` | Команды, сообщения, inline-кнопки, меню Telegram и проверка напоминаний по расписанию | Дает единый API для Telegram и компонент `JobQueue` для периодических задач. |
| `sqlite3` | Файловая база задач | Входит в Python и не требует отдельного сервера. |
| `python-dotenv` | Загрузка `BOT_TOKEN`, `TIMEZONE`, `DB_PATH` из `.env` | Позволяет хранить настройки и токен отдельно от кода. |
| `zoneinfo` и `tzdata` | Работа с часовым поясом пользователя | Помогают правильно принимать местное время и хранить сроки в UTC. |

В SQLite сохраняются ID пользователя и чата, внутренний ID и видимый номер задачи, название, приоритет, срок, статус, дата создания и выполнения, настройка напоминания и дата его отправки. При чтении и изменении задач проверяется ID владельца.

## 5. Трудности и решения

| Проблема | Как решили |
| --- | --- |
| Внутренний ID SQLite не уменьшался после удаления. | Отделили видимый номер от внутреннего ID и перенумеровываем открытые задачи после изменений. |
| Выполненные задачи продолжали занимать номера, поэтому единственная открытая задача могла иметь №3. | Номера выделяются только открытым задачам; выполненные сохраняются для статистики без номера. |
| Задачи без срока, добавленные сегодня, не отображались в «Сегодня». | Для таких задач учитывается местная дата создания; задачи со сроком по-прежнему отбираются по сроку. |
| После повторного использования номера старая кнопка могла бы воздействовать на новую задачу. | В callback-кнопках оставлен неизменяемый внутренний ID, а номер используется в отображении и текстовых командах. |
| Задачи выводились по приоритету и сроку, хотя ожидался порядок номеров. | Для `/tasks` и `/today` установлена сортировка по видимому номеру. |
| Кнопка «Меню» не отображалась как на примере. | Через Telegram API проверены настройки: общий список команд был пуст. Команды зарегистрированы в общем и приватном списках, а `/start` настраивает меню личного чата. |
| Время пользователя и время хранения могут различаться. | Срок вводится в часовом поясе из `.env`, а в SQLite сохраняется в UTC. |
| Периодическая отправка напоминаний требует дополнительной зависимости. | В `requirements.txt` указан вариант `python-telegram-bot[job-queue]`. |

Локально проверены синтаксис, операции с SQLite, миграция нумерации, изоляция пользователей, безопасность старых кнопок, порядок задач и формирование настроек меню. На копии базы проверено, что после завершения задач №1 и №2 оставшаяся задача становится №1; рабочая база также обновлена. Через Telegram API проверено, что общий и приватный списки содержат все 10 команд и кнопка меню настроена на их показ. Скриншоты и видео работы в клиенте Telegram оставлены для заполнения.

## 6. Выводы

### Что получилось хорошо

Бот выполняет основные операции с задачами, сохраняет данные после перезапуска и использует короткие русскоязычные ответы. Управление доступно через кнопки и постоянное меню команд. Отдельная видимая нумерация поддерживает непрерывный список открытых задач с №1, не нарушая работу старых кнопок.

### Что можно улучшить

В дальнейшем можно добавить повторяющиеся задачи, поиск, фильтры по приоритету, настройку произвольного времени напоминания и автоматические интеграционные тесты с тестовым Telegram-ботом.

### Чему научились

В ходе работы освоены обработчики команд и callback-кнопок, настройка меню Telegram через Bot API, пошаговый ввод, параметризованные SQL-запросы, работа с часовыми поясами и планирование напоминаний. Проверка реальных настроек Telegram показала, что корректный код и отображение интерфейса у пользователя необходимо проверять отдельно.
